# ซ้อมสอบ Bebras

เว็บซ้อมข้อสอบ **Bebras** (การคิดเชิงคำนวณ) ทำงานในเบราว์เซอร์ล้วนๆ ไม่ต้องติดตั้งอะไร ไม่มีเซิร์ฟเวอร์ ไม่เก็บข้อมูลออกนอกเครื่อง

## ใช้งาน

- **สอบจำลอง** เลือกชุด (ซ้อมสั้น / ระดับต้น / ระดับสูง) → จับเวลาถอยหลัง → ข้ามข้อ ย้อนกลับ ทำเครื่องหมายไว้ทบทวนได้ → ส่งข้อสอบแล้วดูคะแนน เฉลย และวิธีคิดทุกข้อ
- **ข้อสอบเปลี่ยนไปเรื่อยๆ** โจทย์ถูกสร้างจาก "รหัสชุด" รหัสเดียวกันได้ข้อสอบชุดเดียวกัน (ทำซ้ำ / ทำพร้อมเพื่อนได้) กด "สุ่มชุดใหม่" ได้ชุดที่ไม่เคยเจอ และมี "ชุดประจำวันนี้"
- **ฝึกทีละแบบ** ไม่จับเวลา ตรวจคำตอบและดูเฉลยทันที เลือกหัวข้อที่ยังไม่แม่น
- ปิดหน้าเว็บกลางคันแล้วเปิดใหม่ ทำต่อได้ (เก็บในเครื่องด้วย localStorage) และมีประวัติคะแนนล่าสุด
- รองรับมือถือ โหมดสว่าง/มืด และใช้แป้นพิมพ์ได้

## โจทย์ 17 แบบ

| ระดับ | หัวข้อ |
|---|---|
| A (ง่าย) | ลำดับตัวเลข · แผงหลอดไฟไบนารี · รหัสซีซาร์ · นับสมาชิกสองกลุ่ม · รหัสภาพขาว-ดำ (บีบอัดข้อมูล) · หุ่นยนต์เดินตามโปรแกรม |
| B (กลาง) | เส้นทางสั้นที่สุด · สลับให้เรียง · ถามให้น้อยที่สุด (แบ่งครึ่ง) · นับเส้นทาง · เขียนโปรแกรมให้หุ่นยนต์ · รถไฟกับทางแยกตัน (สแตก) |
| C (ยาก) | ใครพูดความจริง · เครื่องอ่านสายอักษร · ตวงน้ำสองถัง · ระบายสีกราฟ · วางแผนงานให้เสร็จเร็วที่สุด |

รูปแบบคำตอบมี 5 แบบ: เลือกตัวเลือก, ตัวเลข, ข้อความ, แตะช่อง/หลอดไฟ, และต่อลำดับคำสั่งหุ่นยนต์

## ข้อควรรู้ (ความตรงไปตรงมา)

- โจทย์ทั้งหมด **เขียนขึ้นเอง** ในแนวเดียวกับ Bebras ไม่ใช่ข้อสอบจริงและไม่ได้คัดลอกมา
- ข้อมูลที่ยืนยันได้จากเว็บทางการ: Bebras Thailand จัดโดยคณะเทคโนโลยีสารสนเทศ สจล. (KMITL) แบ่งระดับประถมปลาย / มัธยมต้น / มัธยมปลาย ปี 2025 สอบออนไลน์ 3–14 พ.ย. เปิดระบบ 07:00–19:00 ทุกวัน (ดู [it.kmitl.ac.th](https://www.it.kmitl.ac.th/en/posts/bebras-thailand-2025-national-challenge-on-informatics-and-computational-thinking) และ [bebras.in.th](https://www.bebras.in.th))
- **จำนวนข้อ เวลา และเกณฑ์คะแนนของข้อสอบไทยจริง หาจากแหล่งทางการไม่พบ** จึงตั้งเป็นค่าประมาณตามรูปแบบสากล: ระดับ A/B/C ตอบถูก +6/+9/+12, ตอบผิด −2/−3/−4, ไม่ตอบ 0 (ไม่ต่ำกว่า 0) ถ้าครูแจ้งตัวเลขจริง แก้ได้ที่ `B.PRESETS` และ `B.POINTS` ใน `js/core.js`
- ข้อสอบจริงมีแบบลากวาง/โต้ตอบที่ซับซ้อนกว่านี้ ที่นี่ทำแบบที่ใกล้เคียงและฝึกวิธีคิดเดียวกัน
- ควรลองทำโจทย์ตัวอย่างจริงที่ [practice.bebras.in.th](https://practice.bebras.in.th/) ควบคู่กันด้วย

## เปิดเป็นเว็บบน GitHub Pages

1. ไปที่ **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main**, โฟลเดอร์ **/ (root)** → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/bebras-practice/`

หรือเปิดไฟล์ `index.html` ในเครื่องตรงๆ ก็ใช้ได้

## เพิ่มโจทย์ใหม่

เพิ่ม generator ใน `js/tasks/level-a|b|c.js` ด้วย `Bebras.register({ id, topic, title, level, gen(rng) {...} })` ส่งคืน `{ type, prompt, answer | judge, explain, ... }` โดยใช้ `rng` (สุ่มแบบกำหนดเมล็ด) เท่านั้น แล้วเขียน solver อิสระใน `tests/solvers.js` ให้ตรวจเฉลย

## การทดสอบ

```
node tests/run.js 1500                  # สร้างโจทย์ทุกแบบ 1,500 ชุด แล้วตรวจเฉลยด้วยตัวแก้โจทย์อิสระ (ไม่ต้องติดตั้งอะไร)
node tests/mutants.js                   # แกล้งทำให้ตัวสร้างโจทย์ผิด 17 แบบ ต้องถูกจับได้ทุกแบบ
node tests/e2e.js                       # ทดสอบสอบจริงในเบราว์เซอร์ (ต้องมี playwright)
node tests/app-mutants.js               # แกล้งทำให้ระบบคิดคะแนน/จับเวลา/บันทึกผิด 10 แบบ ต้องถูกจับได้ทุกแบบ
```

`e2e.js` ทำข้อสอบครบทุกชุดด้วยคำตอบที่ถูกต้องและตรวจว่าได้คะแนนเต็ม, ทดสอบตอบผิด/เว้นว่าง/ติดลบ, ทำต่อหลังรีโหลด, หมดเวลาส่งอัตโนมัติ, โหมดฝึก และไม่ให้หน้าล้นจอที่ความกว้าง 360px
